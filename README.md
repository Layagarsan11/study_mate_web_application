Studymate
Studymate is a simple web-based productivity application designed to help students manage their daily tasks and study habits. The website allows users to add tasks, set priorities, track completed tasks, and remove tasks when they are no longer needed.

Features
Add new tasks with task name
Select task priority (High, Medium, Low)
Checkbox to mark tasks as completed
Task completion counter (e.g., 2/5 Finished)
Delete button to remove tasks from the list
Simple and user-friendly interface
Navigation pages (Home, Features, Contact, Login/Logout)
How It Works
Enter a task name in the task input field.
Select the priority level for the task.
Click Add Task to add the task to the list.
Use the checkbox to mark tasks as completed.
Click the Delete button to remove a task from the list.
The progress tracker updates automatically to show how many tasks are finished.
Example:

2/5 Finished ☑ Study JavaScript ☐ Complete Assignment ☑ Exercise ☐ Read Book ☐ Practice Coding
